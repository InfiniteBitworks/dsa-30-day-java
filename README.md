# 30 Days of DSA in Java

A simple web app to learn Data Structures and Algorithms with Java over 30 days.

This roadmap is designed for developers who know Java but are starting DSA from scratch. Each day focuses on a specific concept or problem-solving pattern, followed by a set of problems to practice.

---

## What the 30 Days Cover

* Arrays and strings
* Hashing and prefix sums
* Two pointers and sliding window
* Binary search
* Stacks and queues
* Linked lists
* Trees and BSTs
* Heaps
* Graphs
* Backtracking
* Dynamic programming
* Greedy algorithms
* Bit manipulation and tries

> **Note:** There are around **115 problems** throughout the roadmap, complete with notes and Java-specific tips along the way.

---

## Getting Started

1. Open the web app and start with Day 1:
   [30 Days of DSA in Java Web App](https://infinitebitworks.github.io/dsa-30-day-java/)
2. Your progress is saved automatically in your browser, so you can come back and continue right where you left off.

---

## Recommended Approach

* **Take your time:** The goal isn't to rush through as many problems as possible. 
* **Learn and practice:** Learn the pattern, try the problems yourself, understand the ones you get stuck on, and revisit the problems you couldn't solve initially.

> **Expectation:** 30 days won't make you an expert, but it will give you a solid foundation to keep building on.
